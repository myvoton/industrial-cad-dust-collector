# industrial-cad-dust-collector

工业环保设备（脉冲布袋除尘器、脱硫塔、脱硝SCR）设计院标准 CAD 出图工具。基于 Python + ezdxf 参数化生成全套 DXF 制作图，含 GB 标准图框/标题栏/明细栏、技术特性表、管口表、件号球标、钢板套裁优化、PDF 合并输出。

## 功能特性

- **设计院标准出图**：A1 图幅（841×594），装订边左25mm其余10mm，图幅分区8×6，标题栏180×56，明细栏符合 GB/T 10609.2
- **全套图纸**：目录技说 / 总装 / 壳体 / 灰斗 / 花板 / 喷吹 / 顶盖检修门 / 风道法兰 / 支架平台梯 / 下料套裁 / BOM，共 11 张
- **参数化设计**：修改 `dev_params.py` 即可调整风量、滤袋规格、分室数、板厚等全部参数
- **钢板套裁优化**：货架式(shelf)套裁算法，大件优先+余料填充，同厚度板材分开套裁，综合利用率 80~85%
- **手工尺寸标注**：尺寸线/尺寸界线/实心箭头/文字全手工绘制，文字高度按纸面 mm 固定不随比例缩放
- **多视图组织**：主视图 + A-A剖面 + 俯视/平面 + 局部放大(I 1:2) + 节点详图

## 环境要求

- Python 3.8+
- 依赖：`ezdxf`, `matplotlib`, `openpyxl`

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 生成 11 张 DXF 图纸 + PNG 预览
cd cad
python gen_main.py

# 合并 PDF + 导出材料明细表 xlsx
python make_pdf.py
```

输出文件位于 `cad/drawings/` 目录：
- `FDC_50000_00~10_*.dxf` — 11 张 CAD 源文件（AutoCAD R2018 格式）
- `FDC_50000_00~10_*.png` — 图纸预览
- `50000m3h布袋除尘器_全套图纸.pdf` — 11 页合并 PDF
- `50000m3h布袋除尘器_材料明细表.xlsx` — 28 项材料清单

## 典型设备结构

- **脉冲布袋除尘器**：壳体 + 花板 + 滤袋/袋笼 + 灰斗 + 卸灰阀 + 气包/脉冲阀/喷吹管 + 净气室顶盖检修门 + 进/出风总管与提升阀 + 支架平台梯
- **脱硫塔（喷淋空塔）**：圆柱塔体 + 浆液池区（氧化风管、搅拌器）+ 3~4层喷淋层 + 屋脊除雾器 + 冲洗水管 + 入口烟道 + 出口烟道 + 人孔
- **脱硝SCR**：反应器 + 催化剂层（2~3层+预留1层）+ 喷氨格栅AIG + 烟道旁路 + 声波吹灰器

## 关于 cad-1000-hours

本项目出图规范参考了 Markov 在 HuggingFace 发布的 [cad-1000-hours](https://huggingface.co/datasets/markov-ai/cad-1000-hours) 数据集（1021小时录屏/597工作流/256GB，AutoCAD 502h+SolidWorks 209h，CC BY 4.0）中的设计院出图流程。实际出图采用本项目的 ezdxf 参数化方案，无需下载数据集或训练模型。
